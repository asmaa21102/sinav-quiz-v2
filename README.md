# Sınav — v2

A true/false quiz app in Flutter.

Version 2 of [sinav](https://github.com/asmaa21102/sinav), rebuilt with Flutter 3 and Material 3.

**Try it:** https://asmaa21102.github.io/live/phone.html?app=sinav-quiz (runs in the browser, in a phone frame)

## Features

- Four topics: Flutter, Dart, web and general programming
- 15-second timer per question and an explanation after each answer
- Answer streaks, a results screen with a review, and a saved best score

## Run

```bash
flutter pub get
flutter run -d chrome      # or any connected device

```
